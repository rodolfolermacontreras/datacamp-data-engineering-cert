ALTER TABLE and casting

ALTER TABLE t ALTER COLUMN c TYPE INTEGER USING ROUND(c);
ALTER TABLE t ALTER COLUMN c SET NOT NULL;   -- DROP NOT NULL
ALTER TABLE t ALTER COLUMN c SET DEFAULT 0;  -- DROP DEFAULT

CAST(x AS NUMERIC)   -- standard SQL
x::NUMERIC           -- PostgreSQL shorthand
CAST(txt AS NUMERIC)::INTEGER  -- '878.6' -> 879
  • Trap: '878.6'::INTEGER errors. Go through NUMERIC.
  • NUMERIC = exact, arbitrary precision. REAL/FLOAT = binary rounding.
  • SET NOT NULL fails if NULLs already exist.

  • timestamptz AT TIME ZONE -> local timestamp.

Joins, subqueries, set ops

ON a.user_id = b.user_id   -- any names, keeps both cols
USING (user_id)            -- same name, one col in output
WHERE EXISTS (SELECT 1 FROM s WHERE s.id = b.id)
WHERE id IN (SELECT id FROM f GROUP BY id
             HAVING AVG(minutes) > 200)
WHERE d >= (SELECT MAX(end_date) FROM t
            WHERE project_id = ep.project_id)
  • WHERE = rows before grouping. HAVING = groups after (aggregates OK).
  • INNER drops non-matches. LEFT keeps all left rows (NULLs).
  • EXISTS returns each row once. A JOIN duplicates per match.
  • UNION ALL keeps duplicates (use before SUM). UNION dedupes, slower.
  • Every subquery in FROM needs an alias: ) x.
  • MAX() recovers a value repeated per row after a fan-out join.
  • * 1.00 forces decimal division.

NULL traps

  • NULL NOT IN (...) is NULL, not TRUE. Rows are skipped.
  • Fix: OR col IS NULL, or use NOT EXISTS.
  • col = NULL never true. Use IS NULL.
  • Aggregates ignore NULL. COUNT(*) counts rows, COUNT(col) skips NULL.
UPDATE t SET pref = 'Other'
WHERE pref NOT IN ('Active','Beach')
   OR pref IS NULL;

Stats you must say cleanly

  • Box plot: box = Q1 to Q3. Line = median. Whiskers = within 1.5 x IQR. Dots = outliers.
  • IQR = Q3 - Q1 = box width. Robust to outliers.
  • Outlier rule: < Q1 - 1.5 IQR or > Q3 + 1.5 IQR.
  • Seaborn band = 95% confidence interval of the mean line. Wider at the edges (less data).
  • CI = where the line is. PI = where a new point lands (wider).
  • Skew: scores piled low (right tail) = hard exam. Piled high = easy.
  • Histogram vs bar: continuous bins, bars touch vs discrete categories with gaps.
  • Correlation is not causation. Causal claims need an experiment or causal model.
